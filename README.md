# Cute Romantic Date Invitation 💗

Run locally: `python3 -m http.server 5500` then open http://localhost:5500.

After YES, the visitor can choose a first date, an alternate free date, preferred time, food, place, and leave a note. Submitting shows a summary on screen. It does not send the response to you or store it online; to receive responses remotely, connect a form service or backend.

GitHub Pages: put `index.html`, `style.css`, and `script.js` in the repository root, then commit and push to the branch selected in Settings → Pages.
