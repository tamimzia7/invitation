# Cute Romantic Date Invitation 💗

A responsive, static HTML/CSS/JavaScript date invitation website.

## Run locally
Open `index.html` in your browser. No build tools or backend are required.

## Customize
- Edit the question and text in `index.html`.
- Change colors, fonts, and layout in `style.css`.
- Change the playful NO-button messages in `script.js`.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a **new public repository** (for example: `date-invitation`).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository's root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait a minute or two. Refresh the Pages section; GitHub will show your live URL:
   `https://YOUR-USERNAME.github.io/date-invitation/`

If your repository has a different name, replace `date-invitation` in the URL with that repository name.

## Notes
- This is a static site; GitHub Pages hosting is free for public repositories.
- The NO button moves away when approached or clicked. The YES button opens the celebration screen.
- The Google Fonts connection requires internet; system fonts remain as fallback.
